# 🚒 Application de Gestion des Pompiers (C# WinForms)

---

# 🇫🇷 **Présentation**

Cette application, développée en **C# avec Windows Forms**, permet la gestion complète des **missions**, **pompiers**, **casernes** et **types de sinistres** du SDIS.
Elle offre une interface simple, intuitive et optimisée pour suivre les interventions en temps réel, consulter les données opérationnelles et centraliser les informations essentielles.

---

## 🧰 **Technologies utilisées**

* **Langage :** C#
* **Framework :** .NET / Windows Forms
* **Base de données :** SQLite
* **Architecture :** MVC simplifiée
* **Drivers :** System.Data.SQLite

---

## 🛠️ **Fonctionnalités principales**

### 🔥 Gestion opérationnelle

* Création, modification et suppression de **missions**
* Association d’un sinistre, d’une caserne et des pompiers disponibles
* Suivi de l’état d’une mission (en attente, en cours, terminée)

### 👨‍🚒 Gestion des ressources

* Gestion des **pompiers** : ajout, affectation, disponibilité
* Gestion des **casernes** : localisation, effectifs, véhicules
* Gestion des **sinistres** : typologie, gravité, description

### 📊 Outils et visualisations

* Tableaux de bord récapitulatifs
* Statistiques sur les interventions
* Filtres de recherche et tri avancé

### 🔐 Sécurité

* Système d’authentification
* Vérification des droits selon le rôle (si activé)

---

## 💻 **Installation**

1. Télécharger ou cloner le projet

3. Vérifier la présence du fichier SQLite dans `/Database/`

# 🇬🇧 **Overview**

This application, built using **C# and Windows Forms**, provides full management of **missions**, **firefighters**, **fire stations**, and **incident types**.
Its clean and intuitive interface makes it easy to follow operations in real time and centralize all critical information.

---

## 🧰 **Technologies**

* **Language:** C#
* **Framework:** .NET / Windows Forms
* **Database:** SQLite
* **Architecture:** Simplified MVC
* **Drivers:** System.Data.SQLite

---

## 🛠️ **Main Features**

### 🔥 Operational Management

* Create, edit, and delete **missions**
* Assign incidents, fire stations, and available firefighters
* Follow mission status (pending, ongoing, completed)

### 👨‍🚒 Resource Management

* Firefighter management: creation, assignment, availability
* Fire station management: location, staff, vehicles
* Incident type management: category, severity, description

### 📊 Visualization Tools

* Summary dashboards
* Intervention statistics
* Advanced filtering and search

### 🔐 Security

* Login system
* Role-based permissions (if enabled)

---

## 💻 **Installation**

1. Download or clone the repository
2. Open the solution in **Visual Studio**
3. Ensure the SQLite database file is present in `/Database/`
4. Restore NuGet packages (auto in Visual Studio)
5. Start the application with **F5**
