# 🚒 Application de Gestion des Pompiers (C# WinForms)

## 🇫🇷 Présentation
Application développée en **C# avec Windows Forms** pour gérer les missions, interventions et ressources des pompiers.  
Interface intuitive pour le suivi en temps réel et la visualisation des statistiques.

### Fonctionnalités
- Gestion des missions et interventions
- Tableaux de bord et rapports d’activité
- Système d’authentification sécurisé

## 🇬🇧 Overview
A **C# WinForms application** to manage firefighter missions, interventions, and resources.  
Intuitive interface for real-time tracking and activity reports.

### Features
- Mission and intervention management
- Dashboards and activity reports
- Secure login system
